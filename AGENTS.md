# Publishing model collection changes

After each change to this collection:

1. Verify the affected models, previews, and README links. Push the repository changes to GitHub and verify the remote commit on `main`.
2. Sync the corresponding release files from the sibling `URDF_model_high_res` collection to the [shared Google Drive folder](https://drive.google.com/drive/folders/1EOELXUYSBPEJeD0rUIkJxnlLMDr6IHBV). Update existing files in place and verify the remote contents.
3. Open the live default-branch GitHub README. Verify that every Model Overview image loads, then save a screenshot cropped to the complete table at `../model-overview-github.png`.
